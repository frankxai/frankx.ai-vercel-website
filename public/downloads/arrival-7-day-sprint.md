# 7-Day Arrival Sprint
### Golden Age · Arrival · free activation  
### For creator-operators & solo founders who stall on one meaningful aim

**Live:** https://www.frankx.ai/arrival  
**Promise:** In seven days you leave with one written aim, one named obstacle (Gate class), one when-then plan, and one Keystone dated within 14 days — evaluated as an experiment, not a vibe.

**Not for:** therapy/medical treatment, guaranteed wealth/love/health outcomes, metaphysical “thought creates reality” claims, or people unwilling to take a witnessed action.

**Time:** ~5 minutes/day + ~25 minutes on Day 7.

---

## The simple loop

**Aim → Obstacle → Plan → Keystone → Evidence**

---

## Daily default: Action Prime (~5 min)

Do this every day before your main work block:

1. **Target** — What is today’s one behavior that moves the Keystone (or clarifies the aim)?  
2. **Obstacle** — What will likely block it (be concrete)?  
3. **when-then** — When [trigger], I will [first physical move].  
4. **Rehearse** — Mentally walk the first 30–60 seconds of doing it (steps, not trophy).  
5. **Block** — Put it on the calendar or start within 5 minutes.

Optional (not required for v1): 2 minutes breath + one specific gratitude if state is noisy.

---

## Day-by-day

### Day 0 / 1 — Aim
Write one sentence, present tense, specific and difficult enough to matter:

> I am a person who ________ by ________ (date or clear condition).

Rules: one aim only. No twelve domains. If you have many aims, pick the one whose stall costs you the most this month.

### Day 2 — Obstacle truth
Name the real present obstacle in one line. Then **classify the Gate**:

| Class | Pick one |
|---|---|
| Unclear aim | rewrite aim |
| Skill gap | schedule a practice/learn block |
| Energy/emotion constraint | sleep/move/stress default (Peak State) |
| Environmental friction | change a default or remove a friction |
| Missing system | note “needs Reality Architect later” |

### Day 3 — when-then
Write 1–3 implementation intentions tied to real triggers in your day.

Example: `When it is 09:00 after coffee, I will open the draft doc and write for 25 minutes before Slack.`

### Day 4 — Process rehearsal
Run Action Prime, but spend extra time rehearsing the **steps** of the hardest move (not the celebration).

### Day 5 — Shrink until unmissable
If you haven’t started the Keystone draft, shrink the first action until it is embarrassingly small — then do it today.

### Day 6 — Evidence setup
Create a simple log (note or paper):

| Date | Action taken | Fact observed |
|---|---|---|
|  |  |  |

### Day 7 — Keystone contract + WOOP (≈25 min)

**WOOP**
- Wish  
- Outcome (vivid, honest)  
- Obstacle (already classified)  
- Plan (when-then)

**Keystone = 14-day experiment**

```
Keystone act:
Deadline (≤14 days from today):
Prediction (what should be true if this works):
Leading evidence I will collect:
Acceptance test (binary pass/fail):
Witness / proof location:
Reset rule if failing by day 7 of the 14:
Abandon rule if still failing by deadline:
```

Optional only if Gate class = **missing system**:  
open [realityarchitect.ai/assess](https://realityarchitect.ai/assess) and build the **first** missing layer — do not build five.

## Day 14 — Evidence review (calendar this on Day 7)

Score the contract:

- [ ] Acceptance test passed?  
- [ ] What fact surprised you?  
- [ ] Keep / revise / abandon the Keystone  
- [ ] One correction for the next 14 days  

Feeling “aligned” is not a pass condition.
