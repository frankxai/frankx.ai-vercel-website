## Worked example

Film: Egyptian blue on the Parthenon sculptures, The British Museum.
Object source: https://doi.org/10.15184/aqy.2023.130, Figure 5 and the textiles discussion.
Observation: the investigators mapped surviving blue on the front of the mantle of East Pediment figure L.
Interpretation: the distribution suggests a broad decorative border.
Limit: erosion and crust affect detection; the full original pattern is unresolved.
Material comparison: https://doi.org/10.1039/B902563D, abstract. The 910 nm emission maximum was measured on cuprorivaite in a separate study.

## Three independent prompts for Gemini Deep Research

### Read an ancient pigment
Trace one claim from the Parthenon study (doi:10.15184/aqy.2023.130) to the precise image or passage that supports it. Compare it with the cuprorivaite spectroscopy paper (doi:10.1039/B902563D). Report the material, detector, observable, units and limits of each study. Return a four-row table distinguishing measurement, identification, surviving distribution and reconstructed design. Include stable links, source locators, access date, and one competing interpretation.

### Explain the recovering wire
Find an original nickel–titanium dataset that includes thermal or mechanical history and evidence for a phase transformation. Compare one measured loop with the explanation in Sandia’s shape-memory alloy model. Identify one visible feature a video can show and the instrument required for each invisible structural inference. Return a diagram caption and a six-row evidence table. Record units, sample composition, cycle count, uncertainty, DOI and figure number where available.

### Check an AI-designed crystal
Trace the bulk-modulus example in the MatterGen paper (doi:10.1038/s41586-025-08628-5). Separate requested property, model output, simulated value, synthesised phase, measured value and independent replication. Check the status of each stage as of today. Find the authors’ reported disorder and one limit on generalisation. Return a claim ledger with a source URL and pinpoint locator for every supported entry. Mark missing stages explicitly.
