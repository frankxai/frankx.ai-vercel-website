## Procedures

### Deploy

```bash
pnpm --filter worker deploy --dry-run   # exit 0
pnpm --filter worker deploy
```

Rollback: `pnpm --filter worker rollback --to previous`. Owner: platform engineer. The rollback is
a command in this runbook, not a description of one.

### Nightly index swap went wrong

```bash
node scripts/index-swap.mjs --to previous --dry-run   # exit 0
node scripts/index-swap.mjs --to previous
```

Owner: platform engineer. Window: the previous namespace is retained 24 hours, so this works only
within a day of the swap. After that the rollback is a full re-index, which is step 8 below and is
slower, not impossible. This is finding F2 in `05-trust-boundary.md` in operational form.

### Full re-index (step 8, no dry run possible)

```bash
node scripts/index-macros.mjs --full
```

This step cannot be dry-run safely: it writes a new namespace and consumes write units, so a
"dry run" that did nothing would prove nothing. The read-only probe run instead:

```bash
node scripts/index-macros.mjs --plan   # exit 0, prints "would embed 41 of 512 macros"
```

Owner: platform engineer. Rollback: the previous namespace, per the procedure above.

### Turn the system off

```bash
node scripts/triage-toggle.mjs --off
```

Owner: support lead — deliberately not the platform engineer, because the reason to turn this off
is usually a support judgement, not an infrastructure one. Rollback: `--on`. Tickets accumulate in
the inbox and the manual process continues; nothing is lost, because the system owns no ticket
state (`00-frame.md`, non-goals).

### Weekly eval review

```bash
node scripts/run-evals.mjs docs/architecture/06-evals/cases.jsonl
```

Owner: support lead. Rollback: not applicable — read only. A red case is recorded in `review.md`
and stays red; it is not deleted to make the suite green.
