## Procedures

### Deploy

```bash
python -m services.qa.deploy --dry-run      # exit 0
python -m services.qa.deploy
```

Rollback: `python -m services.qa.deploy --rollback previous`. Owner: platform engineer.

### Monthly re-index went wrong

```bash
node scripts/index-swap.mjs --to previous --dry-run   # exit 0
node scripts/index-swap.mjs --to previous
```

Owner: knowledge manager. Window: the previous namespace is retained seven days. After that the
rollback is a full re-index, which is the next procedure.

### Full re-index (no dry run possible)

```bash
python -m services.ingest.reindex --full
```

This cannot be dry-run safely: it writes a new namespace and consumes write units. The read-only
probe run instead:

```bash
python -m services.ingest.reindex --plan   # exit 0, prints "would embed 412 of 12,000 clauses"
```

Owner: knowledge manager. Rollback: the previous namespace, per the procedure above. Longest
observed run: 41 minutes, inside the durable workflow, not a request.

### Living with the open trust finding

```bash
node scripts/feature-toggle.mjs --name external_upload --state off   # exit 0
node scripts/feature-toggle.mjs --list                               # exit 0, shows external_upload=off
```

Owner: general counsel decides; platform engineer executes. This is the operational form of
`05-trust-boundary.md`'s finding F1: an external upload is a T3 document entering a system with no
label line, so the path is off at the toggle rather than discouraged in a document.

Re-enabling is gated on three things, all of which are commands rather than opinions:

```bash
rg -n "system_prompt +=" services/qa/src/prompt.py                   # expect 0 hits
rg -n "untrusted_clause" services/qa/src/prompt.py                   # expect at least 1 hit
node scripts/run-evals.mjs docs/architecture/06-evals/cases.jsonl    # expect 13 pass, exit 0
```

### Turn the system off

```bash
node scripts/feature-toggle.mjs --name contract_qa --state off
```

Owner: legal ops lead — the same person who runs the citation audit, so that the kill criterion and
the switch are in one pair of hands. Rollback: `--state on`. Askers see a message naming the lawyer
rota, and the queue returns to what it was before this system existed.
