# One Still-Life, Three Native Generators

**TL;DR.** Same prompt. Three native tools that actually returned pixels: Hermes Grok Imagine, Codex `image_gen`, Antigravity `generate_image`. All three passed QA. Earlier interior and droid frames missed the brief and are not shown. FAL was not used. Grok video was not run in this session. The configured Grok quality id still did not appear in the tool result.

Receipt: [`/research/image-curated-2026-08-16/receipt.json`](/research/image-curated-2026-08-16/receipt.json)

## The brief

A single matte-black precision cylinder on dark honed slate, one hairline gold ring at the equator, warm sidelight from the left, soft falloff, shallow focus, quiet product photograph, 16:9. No logos, no type, no people.

## What ran

| Path | Tool result | File | QA |
| --- | --- | --- | --- |
| Hermes / xAI | `grok-imagine-image` (not the configured quality id) | JPEG 1280×720 | Publish |
| Codex CLI | `image_gen.imagegen` | JPEG 1672×941 | Publish |
| Antigravity (`agy`) | `generate_image` | JPEG 1376×768 | Publish |

Codex’s `-i` flag attaches an image to a prompt. Generation used its native `image_gen` tool. Antigravity used `generate_image`. Neither is FAL.

## What we are not showing

An earlier pass asked Grok Imagine for an empty room and a mechanical droid. The room gained a chair and a lamp that looked on. The droid became a mascot. Those frames are not audience results.

Hermes is configured for `grok-imagine-image-quality`. The tool still reported `grok-imagine-image`. There is no quality-vs-fast pair on this page.

Grok Imagine video is a separate backend. This session has no video tool. Not run.

## Analysis

On this one still-life, the three native paths are close enough that the routing question is “which CLI is already in the session,” not a fake leaderboard. Codex stood the object up. Grok and Antigravity kept it on its side. All three kept the gold ring and stayed empty of type.

## FAQ

### Is this Grok 4.6 making pictures?

No. Grok 4.6 is the reasoning model. These stills came from Grok Imagine, Codex image_gen, and Antigravity generate_image.

### Why isn’t FAL here?

It is not a native estate path for this work. We did not use it.
