## Stop defaulting to one model

One model is a hammer. Production is a toolbox. The router is the skill that protects quality and margin.

## Router table

| Job | Preferred class | Fallback | Risk note |
|-----|-----------------|----------|-----------|
| Architecture judgment | Claude-class | strong reasoning model | keep human for money |
| Bulk rewrite | Fast GPT-class | local models | voice gate after |
| Cinematic still | Midjourney/FLUX | GPT Image | brand lock |
| Text layout graphic | Ideogram-class | design tool | claims accuracy |
| Realism video | Veo-class | Runway | rights/brand |
| Stylized video | Kling-class | Luma/Pika | consistency |
| Multi-agent ops | ACOS + MCP | Crew/LangGraph | observability |

## Implementation pattern

1. **Job classifier** — rules first, LLM second  
2. **Budget cap** per job  
3. **Quality score** after generation  
4. **Writeback** of winners to evaluation memory  
5. **Human gate** for public brand surfaces  

## Example: one blog post routing

- Research notes: web + hub (not a video model)  
- Draft: writing agent  
- Voice: guardian script  
- Hero still: image stack  
- Optional 15s explainer: video stack  
- Publish: site repo preview  

## AEO: How do I choose the right AI tool for a task?

Classify the job (judgment, bulk text, image, video, orchestration), match a model family, set a cost cap, then run a quality gate before anything public ships.
