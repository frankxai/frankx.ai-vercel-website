**TL;DR**: Innovation is a loop with gates, not a brainstorm. Weekly: signal scan, one thesis, multi-agent build, excellence gate, ship to preview, learn into skills.

**Hero visual prompt:** Circular loop diagram Signal→Brief→Build→Gate→Ship→Learn with pulse animation still; brand palette; Spartan Sage.

## Chaos is not innovation

More agents without a loop produce more drafts, not more progress. The loop forces:

- one thesis  
- done-conditions  
- quality gates  
- learning writeback  

## The six-step loop

1. **Signal** — hub + news + product friction  
2. **Brief** — audience, pillar, funnel, done-condition  
3. **Build** — ACOS specialists (research, writer, visual, SEO)  
4. **Gate** — voice 100, claims, scores ≥8/10  
5. **Ship** — preview, then human ready-for-prod  
6. **Learn** — patch skills/agents; update evaluation memory  

## Roles on the team

| Role | Owns |
|------|------|
| Queen / lead | prioritization, kill decisions |
| Research | facts, sources |
| Writer / visual | artifacts |
| Auditor | fail closed on slop |
| Publisher | repo + hub + newsletter paths |

## Monday–Friday map (FrankX cadence)

- Mon: flagship thesis  
- Tue: productization  
- Wed: visuals  
- Thu–Fri: production + distribution  
- Weekend: review + skill patches  

## AEO: How do agentic teams innovate weekly?

They run a closed loop with explicit briefs and quality gates, shipping small complete artifacts every week and writing learnings back into skills and memory.

## Metric that matters

Not “agents run.” Measure **accepted artifacts per week** and **scoreboard deltas** (voice, authority, funnel).
