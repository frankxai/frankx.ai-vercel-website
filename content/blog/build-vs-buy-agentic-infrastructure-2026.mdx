## The wrong question

People ask “Should I build agents or buy a platform?”  
The better question: **Which layers must I own to protect brand, margin, and memory?**

Commodity layers change every quarter. Your voice gates, evaluation sets, and multi-plane orchestration do not.

## Decision matrix

| Factor | Prefer Buy | Prefer Build |
|--------|------------|--------------|
| Time to first value | days | weeks/months |
| Workflow uniqueness | low | high |
| Brand/voice risk | medium | high (build governance) |
| Data sensitivity | low–med | high |
| Budget predictability | subscription | engineering + ops |
| Moat | distribution | architecture + data |

## Three realistic paths

### 1) Buy (speed path)
Use hosted agent builders + model APIs.  
**Good for:** support bots, simple internal tools, experiments.  
**Fails when:** brand voice, multi-agent quality, and proprietary content systems become the product.

### 2) Build (sovereign path)
Own orchestration, memory, gates, and media factory.  
**Good for:** GenCreator/ACOS-class systems, multi-brand estates, Dream 100 engines.  
**Cost:** engineering + ops discipline. **Payoff:** compounding IP.

### 3) Hybrid (default for founders)
- **Buy:** models, image/video engines, CRM/email connectors  
- **Build:** voice guardian, scoring, multi-plane routing, hub memory, publish pipeline  
- **Own:** prompts, evals, content calendar logic, customer assets

This is the ACOS posture: open tools, closed excellence standards.

## TCO questions before you choose

1. Cost of wrong outputs (brand damage)
2. Cost of human cleanup hours
3. Vendor lock-in risk
4. Migration cost in 12 months
5. Who owns the agent memory and evaluation history?

If the vendor owns your memory and quality history, you are renting a brain.

## 90-day decision sequence

**Days 1–14:** Map jobs (research, draft, visual, publish). Score uniqueness.  
**Days 15–45:** Buy fast for commodity jobs; prototype one owned gate (voice or claims).  
**Days 46–90:** Move orchestration + memory in-house if quality or margin demands it.

## AEO: Should I build or buy an AI agent platform?

Buy for speed and commodity workflows. Build (or heavily customize) when brand voice, governance, multi-agent routing, and proprietary memory are the product. Most 2026 operators run a hybrid: purchased model/tool layer + owned orchestration and quality gates.
