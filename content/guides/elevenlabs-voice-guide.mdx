## Reference Slice: Founder Journal to Audio Briefing

Before wiring a full multi-agent voice pipeline, build one bounded, inspectable job: turning a published public `/journal` note into a 90-second executive audio briefing with deterministic idempotency and a companion provenance receipt.

1. **Stage 01 (Public note & character boundary):** Read a published public `/journal` entry (`visibility: public`, `published: true`), strip markdown syntax into clean spoken prose, and cap the script at `2,800` characters (`~2.5` spoken minutes).
2. **Stage 02 (Voice-owner consent & allowlist gate):** Verify `voiceOwnerApproved: true`, `editorialApproved: true`, and `cloneProhibited: true` against an allowlisted Voice ID before any network request leaves the server.
3. **Stage 03 (Idempotent synthesis):** Hash `(slug + scriptSha256 + voiceId + modelId)` into a 32-character SHA-256 `idempotencyKey` so repeated runs reuse the existing briefing instead of burning duplicate credits.
4. **Stage 04 (MP3 byte QA & provenance):** Confirm the returned payload starts with a valid `ID3` header (`0x49 0x44 0x33`) or MPEG frame sync (`0xFF 0xE0`), normalize loudness to `-14 LUFS`, and write both the `.mp3` and `.json` provenance receipt.

### When to halt a voice synthesis run immediately

Do not ship uninspected TTS output or retry broken configurations in a loop. Stop the run when:

- **Privacy boundary violation:** the source journal entry is marked `visibility: private` or `published: false`.
- **Missing voice consent:** the selected voice lacks documented owner consent or is not in the approved studio library allowlist.
- **Repeated pronunciation drift:** proper nouns, product names, or acronyms mispronounce on two consecutive takes — add phonetic respelling or SSML `<break>` tags before rendering again.
- **Invalid audio payload:** the HTTP response is smaller than `512` bytes or lacks an `ID3`/MPEG frame sync header.

## When to Use ElevenLabs vs Native Speech-to-Speech APIs

Not every voice problem should be solved with a chained `ASR -> LLM -> TTS` pipeline. As detailed in our [Grok Voice vs OpenAI Realtime vs ElevenLabs architecture comparison](/blog/grok-voice-vs-openai-realtime-vs-elevenlabs), pick the layer that matches your turn-taking and editorial control requirements:

| Architecture Job | Recommended Stack | Typical Latency | Why It Wins |
|---|---|---|---|
| **Published narration, founder briefings, audiobooks, dubbing** | **ElevenLabs (`eleven_multilingual_v2` or `eleven_turbo_v2_5`)** | Asynchronous / ~250–400ms | Exact script lock, deterministic pronunciation, multi-character studio timelines, and reusable voice identity across 29+ languages. |
| **Chained tool-calling agent with custom frontier LLM** | **Deepgram Nova-3 + Claude / GPT + ElevenLabs `eleven_flash_v2_5`** | ~450–700ms turn-to-turn | ~75ms model TTS latency at 0.5 credits/char while preserving full text inspection, guardrails, and custom voice timbre. |
| **Ultra-low-latency native speech-to-speech phone agent** | **OpenAI Realtime API or xAI Grok Voice API** | ~200–350ms native audio | Single WebSocket audio-in/audio-out session without intermediate text transcription hops when custom voice cloning is unnecessary. |
| **Air-gapped or zero-cloud local synthesis** | **Kokoro-82M or F5-TTS (local GPU/Apple Silicon)** | Hardware-dependent | Runs entirely offline when compliance prohibits sending text or voice data to an external cloud API. |

## Voice Library, Cloning Hygiene, and Parameter Tuning

### Choosing and Auditioning Voices

1. **Licensed Voice Library:** Start with pre-cleared narrative or broadcast voices (`George`, `Daniel`, `Rachel`) when shipping daily briefings or product explainers.
2. **Instant Voice Cloning (IVC):** Upload 60–120 seconds of dry, room-echo-free speech recorded on a cardioid dynamic or condenser mic. Avoid noise-gated zoom calls or music beds.
3. **Professional Voice Cloning (PVC):** Available on Creator (`$22/mo`) and above; train on 30–120 minutes of studio-grade recordings for long-form audiobooks and signature founder narration.

### Voice Parameter Baseline

| Setting | Recommended Range | Effect on Delivery |
|---|---|---|
| `stability` | `0.50 – 0.65` | Lower values increase emotional inflection but risk mid-paragraph speed-up; keep near `0.55` for technical briefings. |
| `similarity_boost` | `0.75 – 0.82` | Locks vocal timbre closer to the reference recording without introducing metallic harshness. |
| `style` | `0.05 – 0.18` | Amplifies the speaker's directional style; keep below `0.20` to prevent artificial drama and extra latency. |
| `use_speaker_boost` | `true` | Enhances mid-range clarity on phone speakers and earbuds. |

## Pro Tips for Natural Spoken Cadence

### 1. Rewrite Visual Prose into Spoken Sentences

Written markdown often trips TTS prosody. Before calling the API:

- Strip markdown headings, tables, and inline URLs into natural transitions (our compiler in `lib/voice/audio-briefing.ts` handles this automatically).
- Write out ambiguous abbreviations (`"twenty-two percent"` instead of `"22%"` when emphasis matters).
- Replace em-dashes and parenthetical asides with short, declarative sentences.

### 2. Use SSML Break Tags for Deliberate Pauses

Insert `<break time="400ms"/>` between major thesis shifts so the listener can absorb dense technical points:

```xml
<speak>
  State becomes strategy only when it reaches a real person and returns with evidence.
  <break time="450ms"/>
  Regulate, then rehearse, then ship.
</speak>
```

### 3. Normalize Every Master to `-14 LUFS`

Raw synthesis output varies in peak amplitude across models. Run a deterministic `ffmpeg` pass before publishing to `<audio>` players or podcast RSS feeds:

```bash
ffmpeg -i raw-briefing.mp3 \
  -af "highpass=f=80,acompressor=threshold=-18dB:ratio=3:attack=15:release=180,loudnorm=I=-14:TP=-1.5:LRA=9" \
  -ar 44100 -b:a 128k briefing-master.mp3
```
