_Checked against vercel.com on 19 Oct 2026._

Vercel for builders is the FrankX reading path for the Vercel platform. It is for founders, AI architects, creators, and people who ship SaaS or an agent platform. The constraint is that a lesson on this path stays at the status on the linked Vercel page, and a public beta stays a public beta. The docs stay on [vercel.com](https://vercel.com/docs/ai-sdk). This page is the order to read them.

## Start here

1. [Vercel Ship 2026: a sourced recap for builders](/guides/vercel-ship-2026-recap) is the tour. The [skill map](/guides/vercel-ship-2026-recap#skill-map) is the status index, with each skill linked to its Vercel page.
2. [Vercel AI SDK for builders](/guides/vercel-ai-sdk) is the interface lesson: one TypeScript API, AI Gateway, and the Python SDK that the docs still mark public beta. The calls sit on the [SDK decision matrix](/guides/vercel-ai-sdk#decision-matrix).
3. [Vercel agent runtimes](/guides/vercel-agent-runtime-decisions) is the October split: Python, Daemons, Drives, and the [audience decision matrix](/guides/vercel-agent-runtime-decisions#decision-matrix).
4. [Vercel Ship 2026 decisions for people who ship agents](/blog/vercel-ship-2026-builder-decisions) is the short essay. It points back at the recap and the runtime matrix.

eve stays inside the runtime lesson. The [Agent Stack](https://vercel.com/blog/agent-stack) page marks eve public beta, and the hub keeps eve on that lesson.

## The recording

[Vercel Ship 2026](https://www.youtube.com/watch?v=Fr5vzNknYJE) is the official Vercel recording of the tour. The [Ship page](https://vercel.com/ship) uses that same video as its livestream replay. YouTube lists the upload time as 15 October 2026, 17:09 Pacific. Watch this when you want the tour in one sitting. Use the recap when you want the written claims.

The London morning keynote is [Keynote - Ship 26 London](https://www.youtube.com/watch?v=T1vs9jE-EEI). That is the room recording of the Agent Stack, which names the AI SDK. The written interface is the [AI SDK guide](/guides/vercel-ai-sdk).
