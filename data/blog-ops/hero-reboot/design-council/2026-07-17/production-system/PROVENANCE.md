# Provenance — Decision Instrument v3

## What

Deterministic editorial hero system for the FrankX article
`production-agentic-ai-systems` (Enterprise Agentic Architecture).

## Why not generated scenery

Multi-agent council + independent red team rejected mascot/hardware families.
Article truth is a **four-tier maturity decision**. Exact copy requires a
deterministic composition medium, not an image model.

## How to reproduce

```bash
python data/blog-ops/hero-reboot/design-council/2026-07-17/production-system/render_decision_instrument.py
```

Requires local Microsoft Edge. Writes four PNGs under `public/images/blog/`
and optional ffmpeg thumbs under `production-system/qa/`.
