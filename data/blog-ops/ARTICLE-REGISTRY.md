1. Every new/updated post MUST log: authoring agent, reviewer agent, hero path, prompt path, visual QA score, content accuracy pass, SEO/AEO checklist.

3. Diagrams/infographics: exact-text code/SVG only when labels matter; never as OG/hero.
4. Maker ≠ checker for accuracy claims and tool docs currency.
