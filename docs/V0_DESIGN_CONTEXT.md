# FrankX v0 design context

> Current reference for anyone generating v0 studies for this repository.
> Last updated: 2026-09-19

## Start here

Do not treat this file as a standalone design system.

Use these sources first:

- `design.md`
- `taste.md`
- `AGENTS.md`
- `docs/strategy/v0-mcp-operating-standard.md`

## Current rule

v0 MCP is used to generate interface directions, not to define route truth,
product truth, or release authority.

## Required design signals

- dark-first surface
- proof-led hierarchy
- sentence case labels
- `rounded-full` primary CTAs
- no text animation
- restrained motion with reduced-motion fallback
- no fake metrics, no vague AI marketing language, no copied proprietary work

## Required brief fields

Every v0 brief should state:

1. route or hub
2. audience and job to be done
3. exact page role
4. required evidence blocks
5. forbidden aesthetics and language
6. motion constraints
7. CTA hierarchy
8. component reuse expectation
9. maturity label

## Mature output policy

Default every output to **study** unless a stronger label is explicitly earned.
A preview host is not a deployment claim. A generated page is not a product
until FrankX-owned code, evidence, and release gates say it is.
