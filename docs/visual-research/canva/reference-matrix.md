## Category codes

### Saturated

- Rainbow creative gradients used as a substitute for product meaning.
- Template galleries, mockup carousels, and walls of identical “use case” cards.
- Workflow canvases that demonstrate dragging but do not explain why a node exists.
- Generic “create at scale” promises without a source, reviewer, or measurement boundary.

### Trust expectations to preserve

- Exact first-party capability names and dated sources.
- Canva marks only within Canva’s published brand rules, with no implied endorsement.
- A visible human-review stage before publish.
- A truthful commercial status: no claim that FrankX currently earns Canva affiliate commission.
- Keyboard, focus, reduced-motion, and semantic mobile behavior for the architecture.

### Credible white space

- Make the clickable agent graph the table of contents: each node opens a guide, official source, or measurement view.
- Treat Canva as one governed capability inside a founder operating system, not the whole visual identity.
- Pair an architecture view with editorial evidence: source date, permissions, review state, and downstream KPI.
- Let the mobile layout become a linear operating path instead of a shrunken canvas.
