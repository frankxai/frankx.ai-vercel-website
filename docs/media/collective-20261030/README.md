## Storage and application

Follow `architecture_media_fabric_v2`: new canonical private masters and approved immutable web renditions go to Vercel Blob; existing Vercel Image handles responsive delivery. Metadata/approval belongs in the existing control plane. Git owns this specification and placement manifest. Atlas holds six private thumbnails and six draft review records. No Cloudflare proxy, R2 migration, new store, subscription or extra DAM was created.

The application patch adds an approved-only Design Lab gallery, native inspection dialog, filters, a single scoped GSAP media scene through the existing ScrollScene primitive, responsive CSS, an immutable publisher plan and three behavioral test groups. Production with an empty approved manifest returns not-found. No homepage or navigation rewrite is included.

The publisher defaults to a dry plan. `--upload-private` requires an existing private-store credential and keeps masters private. `--publish` requires cleared originals and source-bound approval metadata before any upload. It validates the whole batch, does not overwrite objects, journals successful writes and atomically emits the approved manifest only after completion. Guest characters cannot publish through this command.

Approval metadata is not authenticated by this patch. The authorized publisher must verify the current control-plane record and evidence before supplying a cleared export. Do not self-approve or describe the helper as a deployed approval service.
