# OpenAI Mastery Pillar — Scene Brief

Date: 2026-07-29

## First read

Choose the right OpenAI mode before learning the wrong workflow.

## Visual hierarchy

The signature asset is a Tier C, code-authored three-lane decision system:

- Chat — think, ask, compare, draft.
- Work — gather context, complete steps, produce a reviewable deliverable.
- Codex — inspect repositories, edit code, run tools, test and review.

The hierarchy must work without motion:

1. Editorial hero and concise product distinction.
2. One interactive role selector.
3. One dominant recommendation panel.
4. Three clear route cards with boundaries and starter workflows.
5. Evidence and freshness sections below the fold.

## FrankX world

- Obsidian base with emerald and cyan used as functional signals.
- Warm white type, direct editorial language, precise technical labels.
- One dominant object per viewport.
- Broad panels and dividers instead of a generic wall of equal cards.
- No decorative network art, fake application screenshots, glowing orbs, or
  generic AI gradients.

## Interaction

- Role selection changes the recommended primary and secondary modes.
- Every mode and role transition emits a privacy-safe analytics event.
- Links remain normal links and usable without JavaScript.
- Motion, if used, is limited to short state transitions and respects reduced
  motion.

## Accessibility

- Semantic buttons and links with visible keyboard focus.
- No color-only distinctions.
- Minimum 44px interactive targets.
- Clear heading order and descriptive external-link labels.
- Desktop and 390px mobile inspection before release.

## Performance

- No WebGL, generated hero media, or autoplay video.
- No new image payload for the decision system.
- The structured, code-authored interface is the premium evidence-bearing
  asset and the correct medium for this content.

## Freshness language

The page is verified on 2026-07-29. It may name current products and releases
only when the source registry carries the same review date. Time-sensitive
Academy events display `Upcoming` or `Replay`, never an ambiguous permanent
label.
