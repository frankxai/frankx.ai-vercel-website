The anchor

Six rounds in four days. Then one, eleven weeks later.

The Model Arena is the plainest test of the method. Every round runs a fixed card of tasks against a fixed set of models, scores each answer against a ground truth written before the numbers existed, and publishes the raw JSON.

The last round was built to separate four models on deep reasoning. It did not separate them, and the receipt says so in the review block, with the routing table left where it was. A null result, published with the same care as a finding, is the page's whole claim in one file.

Method

A grade describes where a claim came from.

Work enters the hub through four stages: a directed scan, a specialist pass, a review that rates each claim, then publication with sources and limits attached. The grade follows the claim into the page, so you can see where the evidence stops and the interpretation starts.
