# FrankX Digital Products and Lead Magnets Design Contract (`DESIGN.md`)

> **Brand scope:** FrankX (`frankx.ai/products`) · **Status:** Canonical repo contract · **Updated:** 2026-11-02

This document defines the visual, structural, interactive, and editorial contract for all digital products, free starter kits, protocol specifications, and book PDFs served from `frankx.ai/products` and `frankx.ai/products/:slug`.

---

## 1. Non-averaged Reference Lock (Refero MCP grounded)

Never average unrelated aesthetics across a single page. Every product surface locks to four complementary Refero references with distinct structural jobs:

1. **Canvas, borders, and telemetry (`Warp` + `Linear Changelog`):**
   - Primary canvas: `#0A0A0B` obsidian void.
   - Elevated card surface: `#111318` or `rgba(255, 255, 255, 0.03)` with `1px solid rgba(255, 255, 255, 0.08)` hairlines (`hover:border-white/20`).
   - Typography pairing: tight display sans (`-0.025em` to `-0.035em` tracking) paired with monospace metadata (`tabular-nums`, file paths, kilobyte sizes, SKU identifiers).
2. **Pre-purchase inspection (`Cycle` Two-Pane `618b2107` + `Select & Preview Template` Flow `1694`):**
   - Every product detail page and waitlist stack renders an interactive two-pane **File Tree Inspector** (`ProductFileInspector.tsx`).
   - Left rail (`38%` desktop width): accessible `role="tablist"` file tree showing exact archive paths and file sizes (`44px` minimum height targets, `ArrowUp`/`ArrowDown`/`Home`/`End` keyboard navigation).
   - Right pane (`62%` desktop width): line-numbered monospace excerpt of the selected markdown, JSON, SQL, TypeScript, or PDF chapter outline, paired with a copy-manifest button and explicit **Good fit if** / **Skip this if** decision boundaries.
3. **Lead magnet preview discipline (`Mural` PDF capture `aca74dc4` + `Polaroid` diagnostic Flow `9471`):**
   - Free books and starter guides show concrete chapter/module breakdowns and real excerpts before any click or waitlist capture.
   - Waitlist items clearly state `Coming soon` and route to `/waitlist?intent=:slug` without implying live checkout stock or instant paid fulfillment.
4. **Schematic visual plates (`Eraser` technical diagramming + `Elektron` hardware telemetry):**
   - Every product carries a deterministic `640x360` (`16:9`) vector SVG schematic plate (`public/images/products/plates/:slug.svg`) generated by `scripts/generate-product-plates.mjs`.
   - Zero raster text soup, zero generic 3D blobs, and zero stock photography. Plates render crisp node-and-bus topology diagrams, waveform lanes, ledger matrices, or chapter folios tuned to each product's domain.

## 3. Editorial & Copy Contract (`frankx/COPY.md`)

All product JSON records (`data/products.json`), catalog cards (`app/products/(index)/page.tsx`, `ProductsShell.tsx`), and detail templates (`app/products/:slug/page.tsx`, `OfferStack.tsx`) enforce five non-negotiable copy rules:

1. **Mechanism-first headlines:** `headline` states what the artifact contains or changes operationally (`headline !== name`). Never repeat the product title as its own headline, and never ship placeholder prose (`provides a substrate for builders in the ... ecosystem`).
2. **Sentence-case badges:** Badges use calm sentence case (`Free download`, `Free guide`, `Free PDF`, `Open source`, `Creator toolkit`, `Architecture kit`, `Advisory guild`, `Coming soon`). Never shout in `ALL CAPS`.
3. **Zero punctuation and contrast tells:** Zero em-dashes, zero rhetorical contrast formulas, and zero vague prestige verbs without a measurable object.
4. **Verified claims and fail-closed commerce:**
   - Never publish unverified track counts, prompt headcounts, or speculative earnings claims.
   - Direct PDF downloads remain restricted to the verified public guides (`vibe-os`, `soulbook`, and the six registered public books: `love-and-poetry`, `spartan-mindset`, `self-development`, `imagination`, `manifestation`, `golden-age`).
   - All unreleased kits and waitlisted offers route cleanly to `/waitlist?intent=:slug` without `InStock` schema claims.
5. **Brand separation:** Mythic worldbuilding catalogs belong to their own sister brand boundary and stay filtered out of the FrankX `/products` catalog view.

## 4. Layout, Motion, and Accessibility Checklist

- **Hit targets:** Every interactive control (`Link`, `button`, filter chip, file-tree tab, copy action) maintains at least `44px` height (`min-h-11`).
- **Focus visibility:** Every interactive element declares an explicit `:focus-visible` ring or outline against `#0A0A0B`.
- **Reduced motion:** Ambient backgrounds stay static; interactive transitions animate `opacity`, `transform`, `border-color`, or `background-color` within `150ms` to `300ms` and respect `prefers-reduced-motion`.
- **Automated verification:** Changes to `data/products.json` or `components/products/*` must pass:
  - `node --test scripts/tests/products-design-contract.test.mjs`
  - `node --test scripts/tests/public-claims.test.mjs`
  - `node --test scripts/tests/download-consent-contract.test.mjs`
  - `node --test scripts/tests/coming-soon-product-schema.test.mjs`
  - `node --test tests/products-and-qualities-links.test.mjs`
