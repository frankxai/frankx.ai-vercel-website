# LLM hub direction · 7 September 2026

Reader: a founder or AI architect selecting a model for an actual workflow.
Job: inspect the new Astra release, compare the right evidence, and define a workload test.
Promise: named sources, visible uncertainty, usable cost arithmetic.
Primary action: compare a workload, then open its evaluation contract.
Signature proof: a vendor benchmark is never presented as our own test.

Current state: public root inspected on desktop, 404. Main contains only six scaffold files. Existing PR #2 remains an independent unfinished Grok implementation; it is preserved, not merged or overwritten.

Three directions considered:

1. **Research observatory — selected.** Dark ink, inherited Palatino editorial headings, system sans controls, ruled tables, restrained teal selection. A readable model record leads to exact comparisons and a cost calculator. No ambient animation; interaction changes the information.
2. **Magazine dossier.** Warm paper, oversized story headings, essay-first navigation. Good for interpretation; makes repeat model comparison unnecessarily indirect. Use the established FrankX article layout for this reader job.
3. **Spatial model graph.** Nodes and edges foreground runtime relationships. Useful for architecture, poor for comparing price/quality evidence. Rejected as the hub's primary navigation.

Visual tier: EXPLAINER for this bounded reference release. Exact data and interactive controls are the subject; generated narrative characters would imply undocumented automation and distract from evidence. The visual system comprises a model dossier, metric comparison, workflow acceptance map, and deterministic OG treatment. Brand names are text references; no partnership or logo claims.

Fonts reuse the operating-system fonts in the original scaffold; no font binaries acquired. Mobile has a dedicated single-column model comparison; tables scroll within labelled regions. Motion is omitted because no temporal sequence needs animation.

Sources influencing information architecture: OpenAI Astra launch (capability-led evidence), OpenAI model docs (explicit limits), Claude pricing docs (operation-specific costs), existing llm-evals runner (separate receipts and policy). No visual trade dress copied.
