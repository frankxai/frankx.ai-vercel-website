# FrankX agent readiness, 16 October 2026

Draft branch `agent/grok/agent-json-markdown-20261015`. Production is still the previous `main`. This file is the operating plan for that gap. It is not a claim that the score moved.

## Outcome

An agent that reaches frankx.ai can find the public MCP server, read the homepage as markdown, and recover from an unknown `/api` path with RFC 9457. The incumbent for discovery is `is-agentic.com`. FrankX copies a format only where a real surface already exists.

## What this slice ships

- `GET /api/mcp/server-card` as `application/mcp-server-card+json`, the SEP-2127 location `<streamable-http-url>/server-card`.
- `GET /.well-known/ai-catalog.json` as `application/ai-catalog+json`, one entry, `urn:air:frankx.ai:mcp:frankx`, pointing at that card.
- The card names transport and version `1.1.0`. It does not list tools. Live `serverInfo.name` stays `frankx`. The card's required reverse-DNS name is `ai.frankx/frankx`, with `_meta.ai.frankx/serverInfoName` set to `frankx`.
- `robots.txt` allows the public reads (`/api/mcp`, `/api/v1`, `/api/quote/`, `/api/dare/`, `/api/md`, `/api/404/match`, `/api/vcard`, `/.well-known/`) and still disallows `/api/` so admin, checkout, webhooks, dashboard, and leads stay out.
- `GET /api/quote/today?tz=NotAZone` returns HTTP 400 `{ error: "Unrecognized IANA timezone." }` instead of an uncaught 500. A valid timezone still returns the same quote document.
- `<meta name="is-agentic-site-type" content="content">`. Their docs say this adds no points. It selects the editorial lens. The pages agents read are the library, essays, and guides.

## Seats

One writer. These seats review. They do not edit this checkout.

- Protocol. Holds SEP-2127, RFC 9457, RFC 9727, and `text/markdown` negotiation to the published member sets. Stops a second invented error shape.
- Security. Holds the robots allow-list, the absence of tools and secrets on the card, and the rule that a catch-all `route.ts` must not make every URL look real.
- Product. Holds the refusals: no invented street address, no empty npm package, no sitewide `Vary` on the HTML homepage, no copy of Is Agentic's rate-limit or pricing files.
