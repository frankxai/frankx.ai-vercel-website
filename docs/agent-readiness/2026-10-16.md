# FrankX agent readiness, 16 October 2026

Draft branch `agent/grok/agent-json-markdown-20261015`. Production is still the previous `main`. This file is the operating plan for that gap. It is not a claim that the score moved.

## Outcome

An agent that reaches frankx.ai can find the public MCP server and recover from an unknown `/api` path, including the exact `/api` URL, with RFC 9457. The incumbent for discovery is `is-agentic.com`. FrankX copies a format only where a real surface already exists. Homepage markdown is not in this branch: AGENTS.md keeps homepage work out of an API change, and the narrow template did not carry the live homepage.

## What this slice ships

- `GET /api/mcp/server-card` as `application/mcp-server-card+json`, the SEP-2127 location `<streamable-http-url>/server-card`.
- `GET /.well-known/ai-catalog.json` as `application/ai-catalog+json`, one entry, `urn:air:frankx.ai:mcp:frankx`, pointing at that card.
- The card names transport and version `1.1.0`. It does not list tools. Card `name` and live `serverInfo.name` are both `ai.frankx/frankx`.
- `GET /openapi.json` as `application/vnd.oai.openapi+json;version=3.1`. The RFC 9727 `service-desc` points at that file. Draft #1040 is the older copy and must not merge over this document.
- `robots.txt` allows the public reads (`/api/mcp`, `/api/v1`, `/api/quote/`, `/api/dare/`, `/api/md`, `/api/404/match`, `/api/vcard`, `/.well-known/`, `/openapi.json`) and still disallows `/api/` so admin, checkout, webhooks, dashboard, and leads stay out.
- `GET /api/quote/today?tz=NotAZone` returns HTTP 400 `{ error: "Unrecognized IANA timezone." }` instead of an uncaught 500. A valid timezone still returns the same quote document.
- `<meta name="is-agentic-site-type" content="content">`. Their docs say this adds no points. It selects the editorial lens. The pages agents read are the library, essays, and guides.
