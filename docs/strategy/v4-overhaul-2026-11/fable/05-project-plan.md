# 05. Project plan: waves 2 to 4 as PR-sized slices

**State:** proposal, 5 November 2026. Every slice is one draft PR on `agent/<harness>/<scope>`, built by one role and reviewed by another, inside the three-open-PR cap per harness. Estimates are estimates: agent hours of focused work, not calendar time, and not yet measured against a run. A slice marked **Frank first** cannot start until the matching question in [06-open-questions.md](06-open-questions.md) is answered.

Standing gates on every slice (not repeated below): `pnpm run type-check`, `pnpm run lint`, `pnpm run ai-slop:audit:strict`, `pnpm run build`; `pnpm run merge:gate` before the PR is marked ready; for any UI change, captures at 375, 768 and 1440, keyboard and reduced-motion checks, `node .claude/ci/web-guidelines-lint.mjs --changed`; review by a different vendor within 24 hours (estate flow rule 2); the hand-back format in [03-editorial-standard.md](03-editorial-standard.md).

Roles: LE line editor, RE research editor, VP visual producer, FE front-end builder, VQ visual QA, SEO, ARCH architect, EIC editor-in-chief, IR independent reviewer (Codex, Grok or Antigravity). Paths that do not exist yet are marked (new).
