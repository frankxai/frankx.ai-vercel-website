## Three rules that cut across every layer

1. **One registry, one renderer.** Every list a visitor sees (tools, partners, investigations, models, waitlists, menu doors) reads one file. A second hand-typed copy of the same list is a defect, even on another page. Where two copies exist today (desktop and mobile menus, `/partners` and `/stack`), the plan reduces them to one source or, where a test pins the duplication, to two copies checked against each other in CI.
2. **A number carries its file.** Any count, date or price in public copy is read from a data file at build time or carries an "as of" date and the file path in a code comment. Hand-typed counts are removed, not corrected (the three ACOS count sets on `app/acos/page.tsx:38-43`, `:107` and `:205` are the standing example).
3. **Failure is a visible state, never a blank.** A registry that is empty, stale or unverifiable renders a labelled state ("Sources pending", "No first-party measurement yet", "Program closed"). It never substitutes a fallback number, hides the section silently, or falls back to another item of the same kind. The receipts manifest (`app/research/model-arena/receipts.json/route.ts:13-16`) and the `/go` resolver (`lib/tools/go-destination.ts:9-30`) already behave this way; the rest of the site should match them.

Owner roles are the roles in [AGENT-TEAM.md](../AGENT-TEAM.md). Several agent files it names are absent from `.claude/agents/` (checked 2026-11-05: `general-cmo`, `general-cpo`, `system-architect`, `design-verifier`, `seo-sentinel`, `aeo-engineer`, `worker-visual-qa`; the `humanizer` skill is also absent). Until vendored, the prompts in [04-agent-prompts.md](04-agent-prompts.md) are the role definitions.

## In practice

Copy agents write words, never numbers. Only the research editor adds to `featured-investigations.ts`, `approved-claims.json` or `analysis.public.ts`. A PR that adds an inline array of tools, partners, counts or products to a page is sent back with a pointer to the registry it should read. A block whose failure state nobody can name is not finished.
