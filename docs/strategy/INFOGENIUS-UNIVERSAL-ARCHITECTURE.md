*Open Architecture Specification & Multi-Brand Extension Framework*

## 1. The Universal Standard Specification

**InfoGenius** is an open, framework-agnostic visual intelligence protocol designed to transform abstract technical concepts, mathematical proofs, and system architectures into publication-grade infographics.

---

## 2. Core Engine Capabilities

1. **Deterministic Research Fact Extraction**:
   - Parses 3 to 5 empirical ground truths (hardware throughput, algorithmic formulas, thermodynamic properties).
2. **Organizing Metaphor Synthesizer**:
   - Maps abstract logic to concrete physical models (e.g., exploded hydraulic manifolds, multi-tier floating glass slabs, wafer-scale silicon dies, golden ratio spirals).
3. **Multi-Depth Chiaroscuro Lighting**:
   - Enforces 3 distinct visual depth layers (foreground focal elements, midground conduits, background ambient environment).
4. **Anti-Slop Visual Protection**:
   - Pure visual metaphors with zero distorted AI text. All labels, code snippets, and mathematical equations live as accessible MDX/SVG overlays.
