### Agent Roles & Behavioral Contracts:
1. **`@acos-supervisor`**: Compiles high-level user directives into structured JSON state machines, enforces token budgets, and manages transitions.
2. **`@research-scout`**: Read-only tools. Synthesizes primary source technical papers, hardware benchmarks, and GitHub pull requests. Never outputs conversational fluff.
3. **`@content-author`**: Generates high-density MDX articles, technical tutorials, and book chapters. Enforces the active brand voice (*Elite Creator. AI Architect. Humble Excellence.*).
4. **`@visual-infogenius`**: Orchestrates bespoke infographic generation across 5 visual traditions with zero-text-slop mandates.
5. **`@integrity-guard`**: Zero-trust adversarial reviewer. Executes deterministic compiler gates (`tsc --noEmit`), regex slop checkers (`audit-ai-slop.mjs --strict`), and broken link audits.
6. **`@deployment-orchestrator`**: Updates route registries, triggers cache rebuilds, and commits clean atomic git diffs to production.

## 4. The Adversarial "Santa Loop"

For all mission-critical dispatches and architectural guides, generation is subjected to the Santa Loop:

$$\text{Generation Step (Fire Gate)} \iff \text{Adversarial Critique (Crown Gate)}$$

1. **Fire Gate (Generation)**: The drafting subagent generates the initial thesis, code snippets, and diagram specifications.
2. **Crown Gate (Review)**: An independent reviewer subagent critiques the draft against `TASTE.md`, the Banned Word List, and factual ground truth.
3. **Consensus Convergence**: If score $< 9.5/10$, the reviewer issues specific correction diffs back to the drafter. Only upon mutual cryptographic sign-off does the asset proceed to deployment.

Antigravity provides unique primitives that elevate swarm execution beyond traditional single-agent CLIs:

1. **Dynamic Subagent Registration (`define_subagent` & `invoke_subagent`)**:

2. **Native Multimodal Generation (`generate_image`)**:
   - Direct integration with high-resolution image diffusion pipelines without external third-party GUI dependencies.
3. **MCP Tool Wire Protocol**:
   - Native connectivity to Starlight Memory Vaults, Graphiti temporal graphs, and V0 UI generation pipelines.
4. **Background Task Scheduling (`schedule` & `manage_task`)**:
