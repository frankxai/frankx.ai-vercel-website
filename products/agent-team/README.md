# FrankX Agent Team
## Turn one business brief into a reviewed content and offer package.
Version 0.1.0-beta.1 · Private evaluation candidate · Paid checkout closed

Start with START-HERE.html. It works offline and contains the complete setup guide, copyable instructions and worked examples. Your business context stays on your device until you choose to paste it into your AI account. The page makes no network requests and does not save your entries automatically. Export your context before closing it.

The five roles are Director, Researcher, Strategist, Creator and Reviewer. Run them in sequence in a chat you control. Each role produces a handoff you can inspect. A role name does not create an independent agent, a second model or background execution.

## Your first useful result
1. Extract the ZIP. Open START-HERE.html in a current desktop browser.
2. Fill the context form and save its Markdown export. Read one worked example.
3. Open a fresh conversation in your own ChatGPT or Claude account. Copy TEAM.md into it, then your context. Ask it to run only the Director stage.
4. Read the brief. Correct it, then type APPROVE BRIEF v1. Continue one stage at a time using workflows/content-and-offer.md.
5. Open a fresh chat for the Reviewer, using the reviewer card, full source ledger, brief and draft. Save its verdict. This reduces shared context bias; it is still model review, not independent factual verification.
6. Resolve the findings. Save the final package and approve it yourself before publishing manually.

Success means you can save one post, one offer paragraph, one clear call to action, a claim ledger and a three-task weekly plan; every factual claim is supported or removed. It does not mean a model wrote “passed”.
