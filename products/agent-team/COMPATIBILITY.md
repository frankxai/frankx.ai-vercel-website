# Compatibility and requirements
Version 0.1.0-beta.1 is plain UTF-8 Markdown and a self-contained HTML guide. A ZIP extractor, text editor and current browser are sufficient to read it. No command line, extension, API key or installation script is required.

## AI accounts
The intended hosts are ChatGPT and Claude conversations that can accept pasted text. Use your own lawful account; provider charges and limits remain yours. The kit makes no API requests and includes no model credits. File uploads, Projects, custom instructions, memory and web browsing are optional provider features and are not prerequisites. The reliable fallback is copy/paste, one stage at a time.

Host-interface verification is pending for both providers. No plan, model version, context limit, mobile feature or upload format is certified by this release. Before purchase opens, the operator must record an actual first run in each advertised host, including account tier, model shown, date, interventions and saved output. Do not advertise “tested with ChatGPT and Claude” until those records exist.

## Feature boundary
Included: text instructions, manual context transfer, evidence checks, handoffs and human approval steps.
Excluded: autonomous teams, parallel model calls, connectors, posting, background work, persistent memory, hosting, custom consulting or guaranteed sales. One chat switching roles is one model session. A fresh reviewer conversation is a separate context, not proof of independent truth.

## Privacy and recovery
The offline guide makes no network requests and has no analytics. It does not save context automatically. Save Markdown using the export button. Your AI provider receives anything you paste there; review its data settings and your client permissions. Keep sensitive data out of the initial test. Save the current handoff and source ledger before leaving a chat. Resume with templates/handoff.md.

## Accessibility
All instructions are available as text files. The HTML uses native controls, visible focus, responsive layout and no animation. On phones, a text editor or browser may handle local files differently; desktop setup is the intended beta path. Mobile installation remains unverified.
