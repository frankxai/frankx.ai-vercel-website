## Estimate one seat

Use actual measured provider charges when available. The following worksheet is algebra, not a price quote.

`monthly contribution = price - completed_jobs × captures_per_job × measured_cost_per_capture - infrastructure - support - payment_fees`

Include speech, storage/egress, retries, refunds, hardware, customer acquisition, taxes and salaries where applicable. Reject an apparently cheap token cost when correction/support eliminates the margin. Measure accepted jobs separately from attempts.

## First experiment

Run `npm test`, start the server and run the interactive demo. Replace the mock instruction/fixture with a permitted task. Ask a user to review the exact proposed note, including target and uncertainty. Measure capture-to-accepted-record time. Preserve a phone fallback until a physical device test proves the advantage.

Transfer exercise: adapt to inventory. Change the server-controlled purpose and allowed destination together with fixtures and policy tests. Explain why renaming the client profile does not establish device compatibility.

## Native release checklist

- Exact SDK, toolchain, device and firmware versions recorded.
- Source-checked example has been compiled locally and actually run.
- Permission denial, disconnect, audio-only state and offline recovery tested.
- Real capture and bystander rules established for the deployment.
- Platform terms, publishing eligibility and paid-pilot permission resolved.
- Cloud inference separate consent and data handling verified.
- Actor/tenant-bound durable approval, idempotency and revocation verified.
- Cost cap and deletion/export tested.
- No hazardous/safety-critical use assumed permissible.
- Native code and vendor SDK binaries retain their own terms.

This is a preparation checklist, not a compliance certification.
