# /infogenius-starlight - Starlight Intelligence Visual Generator

**Usage:**
```
/infogenius-starlight "<system_topology>" [style=neural-cosmos|cyber-observability|liquid-starlight|sovereign-mesh]
```

**Description:**
Generates neural cosmos, fleet observability, and cybernetic telemetry infographics for Starlight Intelligence Web OS.

**Execution Sequence:**
1. Ground against `_intelligence/README.md` and Starlight OS principles.
2. Select target style (`neural-cosmos`, `cyber-observability`, `liquid-starlight`, `sovereign-mesh`).
3. Compile prompt with deep navy `#050B14`, starlight gold `#FCD34D`, and cyan `#00E5FF` palettes.
4. Generate image via `generate_image` and save to visual assets vault.
