# frankx ceremonies

This file is the production pointer. It does not copy the crew.

Repo: `frankx.ai-vercel-website`
Runner: `node scripts/ceremonies/run.mjs <id> --brief "<brief>" --out <dir>` in `claude-code-config`.

- `/morning` seats researcher, strategist, maker, editor. Object `morning-piece`. Rival: a content calendar. Refusal: Does not post or publish the piece.
- `/press` seats design-sight, emil-design-eng, corps-design. Object `press-page`. Rival: a component library demo. Refusal: Does not grow the stub button into a component-kit skin.
- `/essay` seats research seat, draft seat, Ma'at. Object `essay-draft`. Rival: a factory checklist. Refusal: Does not publish a number without a source.
- `/orchestra` seats prompt-conductor, prompt-red-team. Object `prompt-score`. Rival: a single mega-prompt. Refusal: Does not keep a prompt that skipped the red team.
