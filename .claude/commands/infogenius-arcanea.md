# /infogenius-arcanea - Arcanea Mythic Infographic Generator

**Usage:**
```
/infogenius-arcanea "<gate_or_topic>" [style=sacred-geometry|illuminated-lore-scroll|mythic-fantasy|character-tome]
```

**Description:**
Generates sacred geometry, cosmic gate charts, and illuminated lore scrolls for Arcanea Creative Worlds and Academy.

**Execution Sequence:**
1. Ground against `.arcanea/lore/CANON_LOCKED.md` and the Ten Gates framework.
2. Select target style (`sacred-geometry`, `illuminated-lore-scroll`, `mythic-fantasy`, `character-tome`).
3. Compile prompt with Arcanean cosmic void, sacred gold, and Atlantean teal palettes.
4. Generate image via `generate_image` and save to visual assets vault.
