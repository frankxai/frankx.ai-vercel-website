# /infogenius-frankx - FrankX Technical Infographic Generator

**Usage:**
```
/infogenius-frankx "<topic>" [style=da-vinci-technical|photorealistic|3d-isometric|business-professional]
```

**Description:**
Generates high-precision, publication-grade infographics for FrankX AI Architecture, Compute Infrastructure, and Sovereign Agent systems.

**Execution Sequence:**
1. Ground facts via WebSearch / codebase research.
2. Select target style (`da-vinci-technical`, `photorealistic`, `3d-isometric`, `business-professional`).
3. Compile 3-lens prompt with FrankX dark obsidian + emerald/cyan/amber palette.
4. Generate image via `generate_image` and save to `public/images/blog/generated/`.
5. Embed into article with ASCII topology diagram and figure caption.
